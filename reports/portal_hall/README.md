# Референсы: Зал Порталa — два стиля

Сгенерировано ИИ как **референс** (по ТЗ: «сделай ИИ референсы нового здания где будет портал в 2 стилях,
заброшенный для обычного мира и для кастомного мира не заброшенный, просто референсы сам его не делай»).
Само здание в мод **не строится** — это только визуальные референсы на будущее.

## 1. Обычный мир — заброшенный

Файл: `ref_abandoned_overworld.png`

* **Силуэт**: полуразрушенный павильон-обсерватория с высокой аркой, уходящий в склон холма; часть кровли
  обвалилась, балки торчат наружу.
* **Материалы**: серый камень, треснувшие кирпичи, медные вставки с патиной, тёмный дуб, кованые цепи.
* **Портал**: мёртвый каменный круг на просевшей платформе, грани выбиты, портал не активен.
* **Разрушение**: проломы в стенах, осыпи на полу, лужи, вьюн и плющ по стенам, покосившийся фонарный столб,
  выцветшие знамёна с вышитым кругом-эмблемой.
* **Свет**: пасмурный вечер, холодный серо-зелёный, руны слабо тлеют бирюзой.
* **Настроение**: тишина, забвение, «здесь давно никого не было».

## 2. Кастомный мир (Элисара) — не заброшенный

Файл: `ref_pristine_elisar.png`

* **Силуэт**: тот же павильон-портал, но целый: стройные колонны, высокий архивольт, лёгкий второй ярус.
* **Материалы**: светлый известняк, белое золото, тёмно-бирюзовая плитка пола с латунным инкрустированным
  узором, светящиеся руны в фризах.
* **Портал**: целый круг с бирюзовым водоворотом, на ступенчатом подиуме, вокруг — мозаичный диск пола.
* **Жизнь**: кораллы и актинии в кадках-бассейнах вдоль стен, вьющиеся растения по парапетам,
  подвесные фонари, «живые» окна на море.
* **Окружение**: бирюзовое море, парящие острова с ярусными кронами и водопадами по краям.
* **Свет**: яркий полдень, насыщенная тропическая палитра.
* **Настроение**: величие, ухоженность, «сюда только что вошли».

## Что взять в реализацию (когда дойдёт очередь)

| Элемент | Заброшенный | Не заброшенный |
|---|---|---|
| Материал стен | `castle:ashlar` + `bricks_cracked` | `castle:ashlar` + латунь |
| Пол | плиты с проломами, лужи | `mosaic` диск + `lab_tile` |
| Портал | `demon_gate` неактивный | `launch_core` активный |
| Растительность | `elisar_ivy`, `dead_moss` | новые кораллы (staghorn/feather) в бассейнах |
| Свет | `emergency_lamp` тусклый | `lab_lamp` + `lantern` |

Референсы лежат в репозитории: `reports/portal_hall/`.
