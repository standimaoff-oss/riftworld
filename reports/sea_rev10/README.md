## Ключевой фикс по сравнению с Рев 9

Раньше вода решалась «по колонке»: первая твёрдая клетка навсегда выключала протечку →
**93% объёма пещер были сухим воздухом**, вода стояла вертикальными столбами.
Теперь полости заливаются **по объёму**, а воздушные карманы задаются отдельным шумом у сводов.
Живой замер: **83% воды / 17% воздуха** в полостях.

## Установка

1. Minecraft **1.20.1** + **Forge 47.4.23** (или новее 47.x).
2. В `mods/` положить `riftworld-0.8.0.jar` (из релиза `v0.8.0`).
3. Новый мир → в портале Разлома выбрать **Элисару**.
4. `/riftsea` (оператор) — проверка моря на месте, если хочется убедиться самому.
