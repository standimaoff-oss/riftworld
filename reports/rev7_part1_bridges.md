## 2. Референс

Твоё фото найдено в репозитории (ветка `standimaoff-oss-patch-1фото`, файл `f0d941a02b4c4758c61eb3462f5d2f54.jpg`) и

## 3. Что сделано (партия 1)

### 3.1 Опора — 3D-модель, 5 стилей (`bridge_post`, `style=0..4`)

Новая модель (2 блока высотой, 19 элементов): плита-плинт → ствол → **обвязка, куда вяжется трос** → железный
бандаж → 4 подкоса → «шляпка» → фонарь в клетке. Текстуры берутся из палитры биома:

| style | Где ставится сам | Плита / ствол / шляпка | Свет |
|---|---|---|---|
| 0 `plains` | обычный мир, город | тёсаный камень / тёмный брус / камень | 12 |
| 1 `garden` | 04 Фиолетовые холмы, 07 Висячие сады | замшелая кладка / сизо / булыжник | 12 |
| 2 `grove` | 05 Роща Сизо | замшелый камень / сизо / камень | 12 |
| 3 `burnt` | **Адские угодья, Тлеющие руины** | обугленная кладка / `charred_log` / scorched stone | 7 (багровый) |
| 4 `mist` | Туманный данж | `keep_stone` / мох / треснувший камень | 10 |

Стиль выбирается **автоматически по биому точки установки** (`setPlacedBy` → `BridgeDeckGeom.styleFor`), а не
яркими предметами. Все палитры приглушённые (правило «не делай яркие слишком»).

### 3.2 Настил — реальный меш с текстурами и светом

`client/BridgePostRenderer` переписан полностью:

- **доски** — поперечные квады 16×16 с кромкой (верх/низ/4 боковины), чередование UV, «выбитые» доски по стилю;
- **два продольных лонжерона** под краями настила (трубы 7.5 см);
- **несущий трос** на каждой стороне: поднимается на «шляпку» опоры (`CABLE_ANCHOR = 1.62`), провис 78 % от
  провиса настила, между ними **вертикальные подвески** каждые 1.25 блока;
- **сетка-рабица** (алмазный узор, `textures/entity/bridge/net.png`) в полосе настил → поручень; у сгоревшего
  стиля вместо сетки — **цепи** и рваные обрывки;
- **провис** настила — катенара ~2 % пролёта (у изношенных стилей ×1.08…×1.28), настил привязан низко
  (`DECK_ANCHOR = 0.22`), поэтому мост выглядит как на фото, а не как «горка»;
- **свет**: `LevelRenderer.getLightColor` в каждой точке — мост освещается солнцем/фонарями/лавой;
- **качание**: клиентская пружина (0.62 амплитуда) от ходьбы/прыжков игрока по мосту, скрип + звон цепи.

Текстуры генерируются детерминированно: `tools/rift/gen_bridge_assets.py` → `assets/riftworld/textures/entity/bridge/`
(`planks_plains|garden|grove|burnt|mist.png`, `cable_rope.png`, `cable_chain.png`, `net.png`).

### 3.3 «Не из блоков» и под углом — коллизия по 1/4 блока

`BridgeWalkBlock` получил свойство **`TOP` (1..16)**: каждая невидимая клетка настила несёт свою высоту в 1/16
блока. `BridgeDeckGeom.collisionCells()` сэмплирует поверхность каждые **0.25 блока** по длине и 4 раза по ширине и
пишет максимум высоты в клетку. Итог: любой уклон, диагональ и перепад высот между опорами (±3) проходятся
непрерывно; при сносе опоры клетки удаляются по тому же расчёту.

Дополнительно: `MAX_LEN` 22 → **26**, проверка второй пары по высоте ±2 → **±3**.

### 3.4 Мировые (генерируемые) мосты — `bridge/WorldBridges.java`

Детерминированно, без сохранённых данных: каждый чанк в `applyBiomeDecoration` вызывает `WorldBridges.place(...)`
и ставит **только свои** опоры и **только свои** клетки коллизии — пролёт может пересекать сколько угодно чанков.

| Где | Что теперь |
|---|---|
| **04 Фиолетовые холмы** | на тропе между двумя церквями там, где она пересекает реку, — **4-опорный садовый мост** (`garden`); старый «брод»/плоский настил убран (`applyChannel(..., ford=false)`) |
| **07 Висячие сады** | редкие мосты через горловины ярусов переведены на 4-опорную схему (`garden`) |
| **Адские угодья / Тлеющие руины** | **сгоревшие** мосты (`burnt`) на **обугленных каменных быках** (`piers`), с обрушенным пролётом (0.44…0.63), провисающими концами и обломками внизу; старый «блочный» мост из `AshenLands.bridge()` заменён на `bridgeDebris()` (только упавшие доски/балка) |
| город / обычный | без изменений — каменные канальные мосты города остались как были |

## 4. Превью (без запуска игры)

`reports/rev7_bridge_preview.png` — оффлайн-рендер геометрии (`tools/rift/bridge_preview.py`, повторяет формулы
`BridgeDeckGeom`/рендера): три стиля, пролёт 13 блоков **по диагонали с подъёмом 1.6** на второй конец; у сгоревшего
— дыра в настиле, провис, цепи.

## 5. Как проверить в игре

```
# 1) творческий режим, любой мир
/give @s riftworld:bridge_post
/give @s riftworld:bridge_rope
# поставить 4 опоры прямоугольником (можно по диагонали, вторая пара ниже/выше на 1-3 блока),
# ПКМ верёвкой по опоре → тянется трос к паре («в длину»), повторить для второй пары,
# ещё раз ПКМ по любой опоре → «в ширину»: собирается настил с тросами, подвесками и сеткой.
# проверить: пройти/прыгнуть (качание + скрип), разбить доску/опору (мост разбирается),
# в аду поставить опору — она сама станет «сгоревшей» (стиль по биому).
```

Мировые мосты: `/rift tp` в 04/07 и в Адские угодья (или `/locate` по своим командам) — мосты уже в генерации.

## 6. Что НЕ входит в партию 1 (следующее)

1. **Деревья** — главная жалоба: движок ветвления/ярусов + **аддон к Dynamic Trees** (решение пользователя:
   «только настоящий аддон», 4 породы). Нужен jar `dynamictrees-1.20.1-*.jar` в `mod/libs/`.
2. Разнообразие стилей внутри одного биома (2–3 варианта опоры на биом) — если попросишь.
3. Пруфы в живой игре: в этой песочнице **нет JDK** и нет доступа к `maven.minecraftforge.net` / `services.gradle.org`,
   поэтому jar не собирался; сборка — `cd mod && ./gradlew build` у тебя.
