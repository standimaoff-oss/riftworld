# Точные Minecraft-референсы левиафана **El Gran Maja**

Сгенерированы напрямую по оригинальным кадрам **El Gran Maja** (`source/real_front.jpg`, `source/real_breach.jpg`, `source/real_profile.png`) с сохранением его настоящей анатомии:
- **Сверхширокая распластанная голова-скала** с боковыми «крыльями»-скулами (как у гигантского ската/усатого кита, в 3–4 раза шире высоты).
- **Куполообразный мшисто-сланцевый лоб** с двумя гроздьями мелких тёмных глаз-бусин (без узкой крокодильей морды).
- **Гигантская широкая пасть-ковш** во всю ширину головы с отдельными зубами (в финальной модели их меньше, они толще и изогнуты по просьбе пользователя).
- **Длинное угольно-чёрное змеевидное тело угря-левиафана**, уходящее далеко назад в ленточный хвост.

## Файлы референсов
1. **[`01_ref_el_gran_maja_waterline_front.png`](./01_ref_el_gran_maja_waterline_front.png)** — фронтальный вид с лодки у кромки воды в тумане (сверхширокая пасть, два пучка глаз на куполе головы, стекающие струи воды).
2. **[`02_ref_el_gran_maja_island_devour.png`](./02_ref_el_gran_maja_island_devour.png)** — кинематографичное выныривание широких челюстей из океана с пожиранием небольшого необитаемого острова целиком рядом с крошечной лодкой.
3. **[`03_ref_el_gran_maja_full_body_model.png`](./03_ref_el_gran_maja_full_body_model.png)** — полный подводный референс игровой модели для Minecraft (анфас + профиль во всю длину тела на фоне обычных рыб и ламинарии).
