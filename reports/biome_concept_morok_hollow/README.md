# Концепт нового биома: **Мороковая Падь** / `riftworld:morok_hollow`

> Страшный, туманный, очень опасный биом-лес. Позже в нём появится **Вендиго** — хозяин чащи.
> Этот файл — только концепт (дизайн + референсы). Код, блоки и мобы — в следующих версиях.

---

## 1. Идея в двух строках

Мёртвый стылый бор, в котором **туман плотнее, чем в остальном мире**: видно на 8–12 блоков, дальше — белая мгла.
Деревья бледные, почти костяные, с чёрными трещинами в коре; земля — мёрзлая, с ледяными клыками и белым мхом.
Биом не «просто холодный», а **враждебный**: игрок теряет ориентацию, слышит шаги за спиной и постепенно замерзает.

**Рабочее имя:** Мороковая Падь (`riftworld:morok_hollow`)
Запасные варианты: «Стылый Бор», «Бледная Пуща», «Тихая Падь».
*(Названия «Гремучая роща» и «Звонкая роща» не используются — запрещены.)*

## 3. Новые блоки (ванильные формы, `БЕЗ ПРЯМ СУПЕР МОДЕЛИ`)

| Блок | Форма / класс | Как выглядит (16×16) |
|---|---|---|
| `morok_log` / `morok_wood` | `RotatedPillarBlock` | бледная кора, редкие чёрные вертикальные трещины; срез — годовые кольца в тон |
| `morok_planks` + stairs/slab/fence/gate/door/trapdoor | полный деревянный набор | холодные серо-бежевые доски, тонкие чёрные стыки |
| `rime_leaves` | `LeavesBlock`, cutout | тёмная хвоя, поверх — белая изморозь «иголками» |
| `morok_sapling` | саженец | тонкий бледный росток с 2 хвоинками |
| `frozen_soil` | обычный блок | почти чёрная земля с ледяной крошкой по краям |
| `rime_grass` | `GrassBlock`-аналог | серо-зелёный мох сверху, мёрзлая земля снизу |
| `pale_moss_block` / `pale_moss_carpet` | блок + ковёр | пепельно-зелёный мох, у ковра 8 соседних форм (как в `v0.20+`) |
| `ice_fang` | `PointedDripstoneBlock`-аналог, но лёд | вертикальные ледяные клыки высотой 1–3, tinted |
| `bone_bramble` | `CrossPlantBlock` (cutout) | сухие белые веточки, ломаются на `bone_meal`… нет, на `morok_twigs` |
| `morok_twigs` | предмет | «палочки» биома |
| `cracked_rime_bricks` + stairs/slab/wall | полный каменный набор | бледный кирпич с морозными разломами |
| `rime_brick_pillar` | колонна | для руин-капищ |
| `fog_lantern` | `LanternBlock`-аналог, `light 7` | тёмная рама, внутри холодное циановое свечение (как в референсах) |
| `wendigo_totem` | 1×1, `light 3`, позже | рогатый череп на шесте — маркер логова, пока только в структурах |

**Крафты:** по правилу мода — практические крафты почти всему, кроме лабораторных и «очень ценных».
`cracked_rime_bricks` ← 4 `frozen_soil` + 1 лёд; `fog_lantern` ← 4 `elisar_chain`/железо + 1 `elisar_eye`-осколок (дорогой, но не «редкий»);
`morok_planks` ← `morok_log` (1 → 4 доски, как требуют базовые крафты).

## 4. Генерация мира

- **Рельеф:** пологие всхолмленные гряды из `frozen_soil`/`rime_grass`, «пади» — неглубокие лощины с туманом, вкрапления `ice_fang` и мёрзлых луж (`ice` + `water` под ним).
- **Деревья:** `morok_hollow_trees` — 1 «палевая сосна» на 5–9 блоков площади, 12–22 блока высотой, крона редкая, асимметричная.
  Крупных скоплений нет: лес **разреженный**, чтобы туман читался.
- **Подлесок:** `pale_moss_carpet`, `bone_bramble`, `morok_twigs`, редкий `rime_leaves`-куст.
- **Структуры:** 3 маленьких, все — руины, без сундуков с лутом выше «железного»:
  1. `morok_shrine` — разрушенное капище 7×7 из `cracked_rime_bricks` с `fog_lantern` и рогатым черепом;
  2. `morok_hunter_camp` — 1 палатка, костровище, черепа;
  3. `morok_wendigo_lair` — логово (кости, тотемы), спавн Вендиго.
- **Шанс спавна:** только честный рандом, без 100 % привязки к биому (как в `v0.30.0`).
- **Океан рядом:** биом не выходит в открытое море, `OceanSurfaceWaves` не трогаем.

## 5. Туман и атмосфера (главная фишка)

- `effects.fog_color = #C9D6D8`, `sky_color = #8FA3A8`, `water_fog_color = #2A3E45`.
- Клиентский **динамический туман**: near ≈ 6–10 блоков, far ≈ 48–64 (сжимается ночью и в лощинах).
  Реализация — как `ShaderCompat`, отдельный слой, чтобы не ломать остальные биомы.
- `ambient_sound`: тихий ветер + редкий треск льда; `mood_sound` — низкий гул с задержкой ~4000 тиков.
- Частицы: редкая ледяная пыль (`minecraft:snowflake`), 0.02.
- **Морок:** раз в 3–6 минут у игрока на 5–8 секунд «двоится» дальний силуэт (клиентская сущность-мира́ж), звук шагов за спиной.
- Туман **не должен** влиять на производительность: никакого пост-процессинга, только параметры рендера.

## 6. Опасность (почему «очень опасный»)

| Механика | Правило |
|---|---|
| Холод | Вне `fog_lantern`/костра: медленное `freeze`-замедление, при 0 °C — урон 1 ❤ / 4 с |
| Дезориентация | В тумане не работают карты/компас на 30 с после входа в биом (кроме `CastleCompass`) |
| Слух | Вендиго «слышит» бег: спринт в радиусе 40 блоков повышает шанс погони |
| Ловушки | `ice_fang` наносит 2 ❤ при падении сверху, `bone_bramble` — 1 ❤ при беге |
| Ночь | Туман плотнее, шанс Вендиго ×3 |

## 7. Мобы

- **Вендиго** (`riftworld:wendigo`) — хозяин биома, 1 на ~600 блоков, ночью/в тумане. Модель — позже (по референсу `02`).
  Поведение: крадётся по краю видимости, атакует со спины, «воет» → игрок получает `darkness` на 6 с.
- **Пегас** (`riftworld:pegasus`) — земля/воздух, приручаемый скакун (см. `../ROADMAP_v0.31_plus.md`). В биоме не спавнится, только в «живых» биомах.
- **Лиоплевродон** (`riftworld:liopleurodon`) — море, глубины, см. роадмап.

## 9. План реализации (черновик, не в этой версии)

1. `morok_hollow.json` + слот в `ElisarBiomeSource` (по образцу `ashen_lands`).
2. Блоки + `BlockSet` (лестницы/плиты/стены/двери), 12 текстур 16×16 по референсу `03`.
3. Фичи: деревья, подлесок, ледяные клыки, мёрзлые лужи.
4. Клиентский туман + `mood_sound`.
5. Структуры: капище, лагерь, логово (+ `/locate`).
6. Вендиго (модель, анимации, ИИ) — после утверждения модели.
7. Пробы в `tools/ci/client_check.sh`: `morok_fog=true`, `morok_trees>=1`, `wendigo_spawn=true`.
