# El Gran Maja — модель для Riftworld

Модель встроена в Forge-мод Riftworld для Minecraft 1.20.1. Исходник Bedrock/Blockbench и воспроизводимый генератор находятся в этой папке; игровые геометрия, границы и атлас копируются в `mod/src/main/resources/assets/riftworld/`. Кадры `01`–`08` здесь — **программные рендеры модели, а не кадры игры**; `09_game_client_front.png`, если присутствует, снят настоящим клиентом.

- 13 связанных костей, 7376 кубоидов; длина около **322 блоков**, ширина **116 блоков**, высота **44,1 блока**.
- Атлас 4096×4096, на каждую ось поверхности — 16 пикселей на блок. Общие проекционные листы намеренно переиспользуют UV.
- 62 отдельных зуба: 32 сверху и 30 снизу; каждый собран из четырёх сужающихся, смещённых секций. Формы и длина различаются; зубы не сводятся к двум ровным рядам прямых иголок.
- Нижняя челюсть — отдельная кость; изображения `04_...` и `08_...` показывают её разные углы. Тело и хвост связаны цепью костей.
- Свод черепа гладкий и герметичный: 0 дыр при трассировке сверху вниз и 0 дыр в затылочно-шейной
  области при трассировке сзади. Все 8 глаз лежат на поверхности — они первыми попадаются лучу
  и в анфас, и в три четверти. Широкое малиновое окно щёк (`u = 0.255…0.445`) опирается снизу на
  диагональный жевательный выступ, снаружи его обрамляет увеличенная скуловая выпуклость
  (по ширине в 2,4 раза больше морды). Это проверяет `verify_head_details.py`.
- `build_collision_bounds.py` строит 13 консервативных ограничивающих объёмов по крайним положениям анимации; `validate_collision_bounds.py` дополнительно проверяет случайные фазы, вращение и идентичность игровых ресурсов. Это проверка геометрии, а не замена испытанию в игре.

## Воспроизведение

Требуются Python 3, Pillow и NumPy:

```bash
python reports/el_gran_maja_model/build_el_gran_maja_model.py
python reports/el_gran_maja_model/validate_el_gran_maja_model.py
python reports/el_gran_maja_model/render_el_gran_maja_shots.py
python reports/el_gran_maja_model/build_collision_bounds.py
python reports/el_gran_maja_model/validate_collision_bounds.py
python reports/el_gran_maja_model/verify_head_details.py
```

Кадры в `ingame/` сняты настоящим клиентом Forge 1.20.1 под Xvfb + Mesa llvmpipe в 1920×1080:
`maja-client-cheeks-front.png` (щёки анфас), `maja-client-cheeks-3q.png` (щёки в три четверти)
и `maja-client-rear-skull.png` (затылок и шея).

Референс и модель сверены в `01_model_front_and_side_ortho.png` и `06_mouth_reference_comparison.png`; масштабный вид — `03_model_three_quarter_scale_with_player.png`. Внешний вид в настоящем клиенте может отличаться из-за освещения, воды и тумана.
